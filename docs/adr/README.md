# Architecture decision records

An architecture decision record (ADR) captures one significant decision: the problem, the
options considered, the one chosen and its consequences. Records use
[MADR 4.0.0](https://adr.github.io/madr/); copy [the template](adr-template.md) to start a new
one, numbered in sequence. A decision that changes is not edited away: a new record supersedes
it, and the old one says so in its status.
